# Sprint 12 — REST APIs

## 📌 Overview

This sprint introduces **REST APIs and data retrieval using Python**, focusing on HTTP methods, response handling, and extracting structured data from external sources.

The practical assignment involves interacting with **public APIs**, performing HTTP requests, processing JSON responses, and transforming retrieved data into pandas DataFrames for analysis and storage.

## 🎯 Learning Objectives

- Understand **REST API fundamentals**, endpoints, and API documentation.
- Perform HTTP requests using **GET, POST, PATCH, and DELETE** methods.
- Interpret **HTTP status codes** and handle API responses.
- Extract, filter, and process **JSON data** from public APIs.
- Convert API responses into **pandas DataFrames** for further analysis.
- Retrieve and export datasets from **open-data platforms** using APIs.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | REST API Fundamentals | Interact with JSONPlaceholder, retrieve posts, users, and tasks, interpret HTTP status codes, handle 404 errors, and perform POST, PATCH, and DELETE requests. |
| ⭐⭐ Level 2 | Public API Integration | Explore public API documentation, identify endpoints and filters, retrieve JSON data using GET requests, and convert responses into pandas DataFrames. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Open Data Extraction | Use the Open Data Barcelona API to discover datasets, query resources using `datastore_search`, retrieve at least 100 records, and export the results to CSV. |

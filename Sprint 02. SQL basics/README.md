# Sprint 02 — SQL Basics

## 📌 Overview

This sprint introduces the fundamentals of **SQL and relational databases**, focusing on data retrieval, filtering, aggregation, and combining information across tables.

The practical assignment involves analyzing company and transaction data to answer business questions using SQL queries of increasing complexity.

## 🎯 Learning Objectives

- Understand relational database structures, including **primary and foreign keys**.
- Write SQL queries using filtering, sorting, logical operators, and **aggregate functions**.
- Combine data from multiple tables using **JOINs**.
- Apply **subqueries** and operators such as `IN`, `NOT IN`, `EXISTS`, and `NOT EXISTS`.
- Extract meaningful business information through structured queries.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | SQL Foundations | Create a relational database, analyze sales by country, and retrieve company transactions using JOINs and subqueries. |
| ⭐⭐ Level 2 | Data Analysis | Identify top-revenue days, calculate average sales by country, and analyze transactions involving competing companies. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Advanced Queries | Filter transactions by dates and amounts, and categorize companies according to transaction volumes. |

## 🛠️ Technologies & Skills

**Tools:** MySQL, MySQL Workbench

**Concepts:** Relational Databases · SQL Queries · JOINs · Subqueries · Aggregate Functions · Data Filtering · Business Analysis

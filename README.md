# 📊 IT Academy | Data Analytics

### Overview

This repository documents my learning journey through the **Data Analytics Specialization at Barcelona Activa's IT Academy**.

The program emphasizes practical, project-based learning, covering the complete data analytics workflow—from data extraction, cleaning, and transformation to statistical analysis, visualization, and data-driven decision-making.

The repository contains hands-on exercises and projects organized into **13 sprints**, demonstrating the application of tools and techniques to real-world data challenges.

### 🎯 Learning Objectives

- Develop proficiency in **SQL and Python** for data manipulation and analysis.
- Work with **relational and non-relational databases**.
- Apply **descriptive statistics** to explore and interpret datasets.
- Build **interactive dashboards and visualizations** using Power BI and Python.
- Retrieve and process data from **REST APIs**.
- Communicate analytical findings to support informed decision-making.

### 📚 Sprint Overview

| Sprint | Topic | Focus |
|---|---|---|
| 01 | Work Environments | GitHub, MySQL Workbench, Python, Power BI |
| 02 | SQL Fundamentals | Relational databases, queries, joins, subqueries |
| 03 | Database Management | Tables, indexes, views |
| 04 | SQL Data Modeling | Database design and modeling |
| 05 | Non-Relational Databases | NoSQL and MongoDB |
| 06 | Descriptive Statistics | Statistical concepts and data exploration |
| 07 | Power BI Fundamentals | Data analysis and indicators |
| 08 | Power BI Visualization | Interactive reports and dashboards |
| 09 | Python Fundamentals | Data structures, functions, programming |
| 10 | Data Analytics with Python | Data manipulation and analysis with pandas |
| 11 | Data Visualization | Visual storytelling with Python |
| 12 | REST APIs | Data retrieval and API integration |
| 13 | Final Project | End-to-end practical data analytics project |

### 🛠️ Technologies & Tools

**Languages:** Python, SQL

**Databases:** MySQL, MongoDB

**Analysis & Visualization:** pandas, NumPy, Matplotlib, Seaborn, Power BI

**Development & Version Control:** Jupyter Notebook, Git, GitHub

### 📁 Repository Structure

Each sprint is organized into a dedicated directory containing its practical exercises and related files. Sprint-specific documentation will provide objectives, key concepts, implementation details, and results.

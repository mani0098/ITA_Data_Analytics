# 📊 IT Academy | Data Analytics Portfolio

### From SQL Fundamentals to Healthcare Machine Learning

## 📌 Overview

This repository showcases my practical work throughout the **Data Analytics Specialization at Barcelona Activa's IT Academy**.

The program follows a hands-on approach to the complete data analytics workflow, covering database management, data extraction, cleaning, transformation, statistical analysis, visualization, and data-driven decision-making.

The repository documents **11 practical sprints**, progressing from foundational SQL concepts to an end-to-end healthcare machine learning project.

## 🎯 Learning Objectives

- **Data Management:** Design, query, and manage relational and NoSQL databases.
- **Data Analysis:** Clean, transform, and explore datasets using Python and SQL.
- **Business Intelligence:** Develop interactive reports, dashboards, and KPIs using Power BI.
- **Programming & Automation:** Build reusable Python functions and integrate external data through REST APIs.
- **Data Storytelling:** Communicate analytical findings through effective visualizations.
- **Predictive Analytics:** Apply statistical and machine learning techniques to real-world problems.

## 🏥 Featured Project — Predicting Prolonged ICU Stays

### Early Prediction of Prolonged ICU Stay in Lung Cancer Patients

**[Explore the Final Project](Sprint%2013.%20Final%20project)**

The capstone project investigates whether clinical information available within the first **24 hours of ICU admission** can predict prolonged intensive care stays (more than five days) among patients with lung cancer.

Using the **eICU Collaborative Research Database (v2.0)**, the study integrates data engineering, clinical feature extraction, exploratory analysis, and machine learning.

**Project Highlights:**

- Developed a modeling cohort of **1,389 ICU stays**, including **286 prolonged stays**.
- Integrated laboratory measurements, vital signs, APACHE variables, and medical history.
- Applied patient-level data splitting, cross-validation, and leakage prevention.
- Developed and evaluated **Logistic Regression and Random Forest** models.
- Assessed predictive performance through ROC-AUC, precision–recall analysis, sensitivity, specificity, and calibration.
- Communicated the findings through a scientific report and visual presentation.

**Project Deliverables:**

- [Final Presentation](Sprint%2013.%20Final%20project/Presentation.pdf)
- [Scientific Report](Sprint%2013.%20Final%20project/Four-Page%20Paper-Style%20Report.pdf)

*The research uses access-controlled clinical data. Patient-level datasets are not publicly distributed, and the predictive models are not intended for clinical deployment without further validation.*

# Sprint 03 — Manipulation of Tables

## 📌 Overview

This sprint focuses on **SQL database management**, including creating, modifying, and deleting tables, managing relationships, and working with indexes and views.

The practical assignment simulates an **online marketplace**, requiring database modifications, transaction management, and the creation of views to support business reporting.

## 🎯 Learning Objectives

- Create, modify, and delete database tables using **SQL commands**.
- Manage **primary and foreign keys** to maintain data integrity.
- Understand SQL data types and database constraints.
- Work with **indexes** to improve query performance.
- Create and manage **SQL views** to simplify data retrieval and reporting.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | Table Manipulation | Create a credit card table, update records, insert transactions, and modify table structures. |
| ⭐⭐ Level 2 | Data Management & Views | Delete specific transactions, create a marketing view, and filter companies by country. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Database Relationships & Reporting | Modify database structures according to an ER diagram and create a technical reporting view combining transaction, user, credit card, and company data. |

## 🛠️ Technologies & Skills

**Tools:** MySQL, MySQL Workbench

**Concepts:** SQL DDL & DML · Table Manipulation · Primary & Foreign Keys · Indexes · SQL Views · Database Relationships · Data Integrity

# Early Prediction of Prolonged ICU Stay in Lung Cancer Patients

## Overview

This repository contains the complete implementation of a reproducible data science pipeline using the **eICU Collaborative Research Database v2.0**.

The project aims to identify factors associated with prolonged ICU length of stay (LOS) among patients diagnosed with lung cancer.

The complete workflow includes:

- Database exploration
- Cohort extraction
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine learning
- Model explainability
- Power BI dashboard
- Final presentation

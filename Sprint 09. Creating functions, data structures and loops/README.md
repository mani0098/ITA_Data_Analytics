# Sprint 09 — Creating Functions, Data Structures and Loops

## 📌 Overview

This sprint introduces **Python programming fundamentals**, focusing on data structures, control flow, and the development of reusable functions to automate everyday tasks.

The practical assignment involves solving increasingly complex programming challenges, from basic calculations and text processing to password generation and automated sports data analysis.

## 🎯 Learning Objectives

- Understand fundamental **Python programming concepts** and problem-solving techniques.
- Work with essential **data structures**: lists, dictionaries, tuples, and sets.
- Implement **conditional statements and loops** to control program execution.
- Develop **reusable functions** for efficient task automation.
- Apply input validation, data transformation, and text-processing techniques.
- Build reproducible solutions to practical programming problems.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | Python Fundamentals | Create a BMI calculator, temperature converters, a word-frequency counter, and a dictionary-reversal function that handles duplicate values. |
| ⭐⭐ Level 2 | Data Structures & Text Processing | Analyze word frequencies from text files, organize results alphabetically, and develop functions to classify and convert different data types. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Automation & File Processing | Develop a configurable random password generator and process football match records to calculate team statistics, identify top performers, and generate league standings. |

## 🛠️ Technologies & Skills

**Tools:** Python, Jupyter Notebook

**Concepts:** Python Functions · Data Structures · Conditional Logic · Loops · Input Validation · File Handling · Text Processing · Data Transformation · Task Automation

# Sprint 05 — Queries with MongoDB

## 📌 Overview

This sprint introduces **NoSQL databases**, focusing on MongoDB and its document-oriented data model. It explores the differences between relational and non-relational databases, along with fundamental database operations and querying techniques.

The practical assignment involves working with a **movie entertainment database**, containing information about users, theaters, sessions, movies, and comments, to extract insights through MongoDB queries.

## 🎯 Learning Objectives

- Understand the differences between **relational and non-relational databases**.
- Explore NoSQL database types: document, key-value, column-oriented, and graph databases.
- Install, configure, and navigate **MongoDB and MongoDB Compass**.
- Perform basic **CRUD operations** (Create, Read, Update, Delete).
- Query and filter JSON documents using **MongoDB query operators**.
- Apply counting, filtering, and geospatial concepts to data analysis.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | MongoDB Fundamentals | Import JSON collections, retrieve documents, count users and movies, and filter movies by genre, language, awards, and release year. |
| ⭐⭐ Level 2 | Filtering & Aggregation | Analyze user comments by email domain and count theaters grouped by postal code. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Advanced Queries & Geospatial Data | Filter movies by director and IMDb ratings, and visualize theater locations on a map. |

## 🛠️ Technologies & Skills

**Tools:** MongoDB, MongoDB Compass

**Concepts:** NoSQL Databases · Document-Oriented Data · JSON · CRUD Operations · Query Operators · Data Filtering · Aggregation · Geospatial Visualization

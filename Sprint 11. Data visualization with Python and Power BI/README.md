# Sprint 11 — Data Visualization with Python and Power BI

## 📌 Overview

This sprint focuses on **data visualization using Python**, exploring static and interactive visualization techniques with pandas, Matplotlib, Seaborn, and Plotly.

The practical assignment involves connecting Python to a **MySQL relational database**, creating visualizations to explore relationships among variables, and integrating Python-generated charts into Power BI for interactive reporting.

## 🎯 Learning Objectives

- Create effective **data visualizations** using Python libraries.
- Select appropriate chart types based on **variable types and analytical objectives**.
- Explore relationships between numerical and categorical variables.
- Apply **correlation analysis** and advanced statistical visualizations.
- Connect **Python to MySQL** to retrieve and analyze relational data.
- Integrate **Python visualizations into Power BI** for business intelligence reporting.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | Data Visualization Fundamentals | Connect Python to MySQL, import the Sprint 04 database, and create visualizations for numerical, categorical, and combined variables, including pairplots. |
| ⭐⭐ Level 2 | Statistical Visualization | Analyze correlations between variables, create joint plots, and interpret relationships and patterns within the data. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Python & Power BI Integration | Reproduce Level 1 visualizations in Power BI using Python scripts and integrate them into a business intelligence report. |

## 🛠️ Technologies & Skills

**Tools:** Python, Jupyter Notebook, MySQL, Power BI Desktop

**Libraries:** pandas, Matplotlib, Seaborn, Plotly

**Concepts:** Data Visualization · Statistical Analysis · Correlation Analysis · Numerical & Categorical Data · Pairplots · Jointplots · Database Connectivity · Python–Power BI Integration

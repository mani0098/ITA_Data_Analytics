# Sprint 10 — Data Analytics with pandas

## 📌 Overview

This sprint focuses on **data analysis and manipulation using Python's pandas library**, covering data cleaning, transformation, aggregation, and statistical analysis.

The practical assignment involves analyzing an **employee survey dataset**, performing data transformations and salary analysis, and solving advanced challenges involving automated data visualization and route optimization.

## 🎯 Learning Objectives

- Create, import, and manipulate **pandas DataFrames**.
- Clean and transform datasets by handling missing values, modifying columns, and converting data types.
- Apply **filtering, sorting, grouping, and aggregation** techniques.
- Perform **descriptive statistical analysis** and generate summary tables.
- Automate data processing tasks using reusable Python functions.
- Develop analytical and algorithmic solutions to practical problems.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | Data Cleaning & Exploratory Analysis | Import employee data, validate identifiers, transform demographic variables, calculate age, and analyze salaries by gender and country using grouped summaries and pivot tables. |
| ⭐⭐ Level 2 | Data Transformation & Automation | Apply salary increases by professional group, automate the export of employee datasets, and generate summary statistics including average salaries and median ages. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Advanced Analytics & Problem-Solving | Develop a reusable function for automatic visualizations based on variable types, and implement a route optimization algorithm to visit Spanish cities while minimizing travel distance. |

## 🛠️ Technologies & Skills

**Tools:** Python, Jupyter Notebook, pandas, NumPy

**Concepts:** Data Cleaning · Data Transformation · DataFrame Manipulation · GroupBy & Pivot Tables · Descriptive Statistics · Data Visualization · File Export · Algorithmic Problem-Solving

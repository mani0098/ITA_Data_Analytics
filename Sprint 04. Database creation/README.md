# Sprint 04 — Database Creation

## 📌 Overview

This sprint focuses on **SQL database design and dimensional modeling**, covering database relationships, data granularity, and the creation of relational schemas.

The practical assignment involves designing and building a **star-schema database** from CSV datasets containing users, companies, credit cards, transactions, and products, followed by analytical SQL queries.

## 🎯 Learning Objectives

- Understand different **database modeling techniques**, including dimensional modeling.
- Distinguish between **dimensions and metrics** in data analysis.
- Design relationships between tables (**1:1, 1:N, and N:M**).
- Understand **data granularity** and its impact on analytical results.
- Create relational databases, define relationships, and import data using SQL.
- Develop and interpret **database diagrams** to represent data structures.

## 💻 Practical Assignment

The exercises are divided into three progressive levels:

| Level | Focus | Key Tasks |
|:---|:---|:---|
| ⭐ Level 1 | Database Design & Creation | Design a star schema with at least four tables, identify users with more than 80 transactions, and calculate average transaction amounts by IBAN. |
| ⭐⭐ Level 2 | Business Logic & Data Analysis | Create a table classifying credit cards as active or inactive based on their three latest transactions, and count active cards. |
| ⭐⭐⭐&nbsp;Level&nbsp;3 | Data Integration & Product Analysis | Integrate product information into the relational model and calculate the number of times each product was sold. |

## 🛠️ Technologies & Skills

**Tools:** MySQL, MySQL Workbench

**Concepts:** Database Design · Star Schema · Dimensional Modeling · Primary & Foreign Keys · Data Granularity · SQL DDL & DML · Data Integration · Business Analysis
